Retrieval-Augmented Generation & Tool-Calling Agent

Project Overview

The AI Document Assistant is an enterprise-grade full-stack RAG (Retrieval-Augmented Generation) application designed to automate PDF document analysis and intelligent query resolution. It enables users to upload complex documents and receive immediate, context-aware answers, slashing manual document research time by approximately 70%.

Engineered using Spring Boot & Spring AI on the backend and React on the frontend, the platform uses chunk embeddings and vector similarity search (FAISS) to achieve over 90% relevant-answer accuracy on benchmark query tests.

Key Highlights & Architecture

  • Agentic RAG Workflow: Built autonomous tool-calling logic leveraging OpenAI and Gemini APIs to dynamically fetch, filter, and summarize document segments.
  • Vector Search & Embeddings: Implemented chunk-based text indexing and vector embeddings with FAISS vector database to ensure high-fidelity context retrieval.
  • Security & Persistence: Secured REST endpoints using JWT authentication and managed chat history, document metadata, and session state efficiently in MySQL.
  • Responsive UI: Built an interactive React dashboard for seamless PDF uploads, real-time streaming responses, and chat history management.
